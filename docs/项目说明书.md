# 招标文件关键条款抽取工具 · 项目说明

> 用途：投售前 / 解决方案 / 实施顾问岗位时，随简历附上的一页说明。
> 读者是不写代码的人（销售、项目经理、HR），所以**不放代码、不放命令**。

**一句话**：把「人读 80 页标书找 12 类条款」变成「机器 2.5 秒出风险清单，人只复核红项」。

---

## 一、背景：漏一条，前面几天全白做

中小企业投一个标，先要读完 60–120 页招标文件：资格要求、保证金、工期、废标条款散落在几十个章节里，
人工找一遍平均要 **45 分钟**。

更麻烦的是会漏——「投标文件未按要求签字盖章」这类条款常常藏在**第 47 页的表格**里，
漏掉一条，前面几天的准备工作就全部作废。

## 二、方案：章节定位 + 关键词窗口 + 置信度分级

不是把整份文件丢给大模型"猜"，而是三步确定性流程：

```
PDF  ──►  三通道解析  ──►  章节定位 + 关键词匹配  ──►  三级置信度  ──►  Excel 报告
          正文 / 表格 / 标题      12 类条款规则库          高 / 中 / 低
```

**三个关键设计：**

1. **表格单独走一条通道**——招标文件里 80% 的关键条款（评分表、资格审查表、签章要求）都在表格里，
   按正文流抽取会把列拼错行。
2. **规则里写"章节代号"不写章节名**——同一章在不同文件里可能叫「投标人须知」或「供应商须知」，
   用代号 + 别名词典兼容，加一种叫法只改一行。
3. **置信度分级而不是非黑即白**——命中在正确章节=高，只命中关键词=中，命中目录行=低；
   **中低一律进「待复核」，不假装确定**。

## 三、价值

| 维度 | 现在 | 用了这个工具 |
|------|------|-------------|
| 时间 | 人工通读 45 分钟 | **2.5 秒**出清单 |
| 风险 | 靠人眼，容易漏 | 12 类条款全覆盖，**召回 100%（零漏判）** |
| 可核对 | "我记得好像有这么一条" | 每条结论**带原文 + 页码**，点回去就能核对 |
| 边界 | —— | 拿不准的标「待复核」，**不硬猜** |

## 四、数据（实测，2 份人工标注文件）

| 指标 | 结果 |
|------|------|
| 微平均准确率 | **90.0%** |
| 召回率（废标类为重点） | **100.0%** |
| 假阳性率 | 10.0% |
| 单份文件端到端耗时 | **2.5 秒** |
| 条款类别覆盖 | 12 / 12 |

*口径说明：微平均按全部判断合并计算。当前样本 2 份，规则在这 2 份上调整过，指标偏乐观；
语料扩到 20 份后按「15 份调参 + 5 份验证」重测。*

## 五、能力边界（主动说明）

- **不做 OCR**：扫描件没有文本层时明确标「需 OCR」，不给不准的结果
- **不覆盖技术参数与产品认证**（CCC、节能清单、检测报告），这类需业务员结合采购需求章节人工核对
- 规则是「关键词 + 章节定位」，不是语义模型；换行业可能需要补词典
