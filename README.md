# 招标文件关键条款抽取与废标风险自查工具

输入一份 60–120 页的招标文件（PDF / DOCX），10 秒内输出一份 Excel 风险自查报告：
**12 类关键条款 + 红/黄/绿分级 + 原文页码 + 复核建议**。

> 状态：**开发中**（2026-11）｜解析层与规则层已完成，风险分级、报告输出与量化评估进行中。

## 解决什么问题

中小企业投标时，一份标书 60–120 页，人工找资格要求、保证金、截止时间、废标条款平均要 **45 分钟**，
而且经常漏——「投标文件未按要求签字盖章」这类条款常常藏在第 47 页的表格里，**漏一条就直接废标**。

一句话：把「人读 80 页找 12 类条款」变成「机器 10 秒出风险清单，人只复核红黄项」。

## 12 类条款

| 代码 | 类别 | 风险含义 |
|------|------|---------|
| C01 | 项目编号/名称 | 填错即无效 |
| C02 | 预算/最高限价 | 超预算直接废标 |
| C03 | 投标保证金 | 未按时足额缴纳即废标 |
| C04 | 投标截止/开标时间 | 迟到 1 分钟即拒收 |
| C05 | 资格要求-资质 | 不满足即不合格 |
| C06 | 资格要求-业绩 | 业绩不达标即不合格 |
| C07 | 资格要求-人员 | 人员不符即不合格 |
| C08 | 评分办法 | 决定报价策略 |
| C09 | 废标条款 | 最高优先级，全部摘出 |
| C10 | 签字盖章要求 | 最高频的低级废标原因 |
| C11 | 联合体/分包 | 影响主体资格 |
| C12 | 投标文件组成 | 缺件即废标 |

## 已知边界（主动说明）

- **不做 OCR**：无文本层的扫描件直接标「需 OCR」，不硬猜——工具的第一价值是可信，不是覆盖面。
- **12 类不覆盖技术参数与产品认证**（CCC 认证、节能清单、检测报告），需业务员结合采购需求章节人工核对。
- 规则是「关键词 + 章节定位」，不是语义模型，换个行业的表述可能需要补词典。

标注过程中发现的更多规则边界与真实文件怪象，见 [docs/观察记录.md](docs/观察记录.md)。
